# 영상식물학 및 표현체학 기말 과제 기획

본 저장소는 '영상식물학 및 표현체학' 수업의 기말 과제를 위한 미니 논문형 보고서와 발표 자료 초안을 포함하고 있습니다.

## 과제 개요
- **주제:** 엣지 AI 기반 실시간 영상 처리 및 표현형 분석을 통한 콜드체인 과실 품질 모니터링 시스템 기획
- **주요 내용:** 
    - 영상 처리 개념(영역 분할, 특징 추출)을 활용한 과실 품질 분석
    - Jetson Orin Nano 및 디지털 트윈 연동을 통한 실시간 모니터링 체계 제안

## 파일 구성
1. **[보고서 (report.md)](./report.md)**
    - 분량: A4 5쪽 상당 (약 2,000자 이상의 학술적 서술)
    - 구성: 초록, 서론, 선행연구(3편), 연구방법, 기대효과, 참고문헌
2. **[발표 자료 (presentation.md)](./presentation.md)**
    - 슬라이드: 총 12장
    - 특징: 각 슬라이드별 상세 발표자 노트(Speaker Notes) 포함

- 본 자료는 마크다운(Markdown) 형식으로 작성되었습니다.
- 보고서는 워드(Word)나 한글(HWP)로 복사하여 서식을 맞춘 뒤 PDF로 변환하여 제출하시기 바랍니다.
- 발표 자료는 PPT의 각 슬라이드 내용과 노트 부분에 그대로 활용하실 수 있습니다.
